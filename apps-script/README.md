# Script Apps Script di EDITH

Copia di riserva del codice che gira in Apps Script. La versione da incollare resta quella nella cartella del progetto.

- `EDITH.gs`: tutto lo script in un unico file. Qui l'ID dello Sheet è sostituito da `INCOLLA_QUI_ID_DEL_TUO_SHEET`, perché il repository è pubblico.
- `appsscript.json`: impostazioni del progetto (servizi Drive, Gmail e Tasks).
- `VOCE_EDITH.md`, `APP_EDITH.md`, `LEGGIMI.md`: le guide.

Nessun token o segreto è salvato qui: il token si crea con `creaTokenVoce` e resta nelle proprietà dello script e sul telefono.
